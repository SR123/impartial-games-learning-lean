1 Paper text

From a game rule to a network. The networks in this appendix are constructed explicitly from the game rules: their connections and weights are specified by an algorithm, rather than found by training. To see what the construction computes, revisit Figure 2. The preceding board Q=(3,5,6)Q=(3,5,6)Q=(3,5,6) has nim-sum zero; after the opponent changes 555 to 444, the current board is Q′=(3,4,6)Q'=(3,4,6)Q′=(3,4,6). Comparing the frames gives δ=5⊕4=1\delta=5\oplus4=1δ=5⊕4=1. In parallel, the circuit proposes replacements (3⊕1,4⊕1,6⊕1)=(2,5,7)(3\oplus1,4\oplus1,6\oplus1)=(2,5,7)(3⊕1,4⊕1,6⊕1)=(2,5,7) and tests which decrease their heaps. Only 2<32<32<3 passes, so the output selects heap index 000 with replacement value 222, giving (2,4,6)(2,4,6)(2,4,6) with nim-sum zero. For B=3B=3B=3 and a two-bit index, the output fields are validity 111, index 000000, and value 010010010.

2 Explain this

The input already includes the missing clue: the preceding board had nim-sum zero. Comparing it with the new board reveals the opponent's change. For (3,5,6)→(3,4,6)(3,5,6)\to(3,4,6)(3,5,6)→(3,4,6) the change is 111, so the replacements are (2,5,7)(2,5,7)(2,5,7). Only heap 0 can be reduced to its proposed value. With three-bit heaps and a two-bit index, the output is validity 111, index 000000, value 010010010. These are fields, not a single integer.

This is the checked two-frame selector run on one example, gate group by gate group. It starts from the two frames of Figure 2 and ends with the binary output fields shown in Figure 7. Every value below is computed from the selector's definition for the boards shown. Choose another example to see several candidates at once, the fallback, or a terminal board. The two examples marked "outside the promise" do not start from a zero-nim-sum board after a legal move, so the guarantee does not apply to them.

Inside the promise. The earlier board has nim-sum 0 and the opponent decreased one heap, so the restoration theorem guarantees that the output restores nim-sum 0.

→→

  1. Compare the frames bit by bit

    Each heap is a 3-bit block. For every heap and every bit position, one two-input XOR compares Q with Q′, all in parallel.

    HeapQ 421Q′ 421XORHeap
    03 0113 011000same

  2. Extract the difference δ

    Bit k of δ is the OR of column k of the XOR table: 001 = δ = 1.

    At most one heap changed, so at most one row is nonzero and the OR equals the XOR of the rows, which is nim(Q) ⊕ nim(Q′).

  3. Propose replacements and test them in parallel

    For every heap at once: replace Q′i by Q′i ⊕ δ and test whether that is a decrease. The decisive bit is the highest set bit of δ (weight 1): a heap passes exactly when it has that bit set.

    HeapQ′ 421Q′ ⊕ δTest
    03 0112 010passes: 2 < 3

    Show the bit comparisons

    The test x ⊕ δ < x is a fixed-depth circuit: an OR over the possible highest differing bit, requiring equality above it, a 1 in x and a 0 in the replacement at that bit.

    • Heap 0: 011 vs 010 — the highest differing bit has weight 1; the heap has 1 there, so the replacement is smaller.
    • Heap 1: 100 vs 101 — the highest differing bit has weight 1; the heap has 0 there, so the replacement is larger.
    • Heap 2: 110 vs 111 — the highest differing bit has weight 1; the heap has 0 there, so the replacement is larger.

    Candidates passing: 1.

How this relates to the Lean proof. The selector is Family.restS (B, N): the local difference circuits LocalRestore.dC, the candidate tests of SelectCircuit.varSel and the priority encoder PriorityEncoder.encode, read on the two-frame input LocalRestore.tf. Family.rest_semantics proves that, on the promised domain, these formulas and the compiled network output a legal move that restores nim-sum 0. Outside the promise the circuit still computes the values shown, and no theorem says that the result restores 0.

What this does not show. The selector does not find a first winning move from an arbitrary board. Given a zero-nim-sum predecessor it maintains the invariant (Theorem 5.12(iii)). The boxes of Figure 7 group operations; the stages here group gates, not network layers.

3 How this is formalised

An explanatory numerical instance of the checked construction, not a separately added Lean theorem. LocalRestore.dC_eval identifies the difference bits; ThresholdInst.restNet_correct proves the full network returns a legal move restoring zero under the preceding-zero and legal-transition hypotheses. The binary interface is PriorityEncoder.restBin.
