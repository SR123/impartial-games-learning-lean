1 Paper text

Remark 5.11 concerns a symmetric observation channel for an unknown bit YYY. Each observation agrees with YYY with probability (1+a)/2(1+a)/2(1+a)/2, where 0<a≤1/20<a\le1/20<a≤1/2, and observations are independent conditional on YYY. A possibly randomised decision rule assigns a probability of outputting 1 to each observed bit vector. Let m∗(a)m_*(a)m∗​(a) be the least sample count for which such a rule has error at most 1/41/41/4 for each possible value of YYY.

2 Explain this

The appendix's setting: an unknown bit YYY is observed through a symmetric channel; each observation agrees with YYY with probability (1+a)/2(1+a)/2(1+a)/2, and observations are independent given YYY. A decision rule (possibly randomised) maps the observed bits to a guess. m∗(a)m_*(a)m∗​(a) is the least number of observations for which some rule has error at most 1/41/41/4 for each value of YYY.

3 How this is formalised

RealNoise.pOf is the agreement probability (1+a)/2(1+a)/2(1+a)/2; RealNoise.chan_law proves that the mmm-sample channel law is a probability law; RealNoise.Ach a ma\ ma m says some randomised rule on mmm samples has both errors at most 1/41/41/4; RealNoise.mMin is the least such mmm (by convention 000 when none exists). RealNoise.mMin_spec: for 0<a≤10<a\le10<a≤1 the minimum exists, is attained and is minimal.
