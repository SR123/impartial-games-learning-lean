2 Explain this

With a single fixed head, every allowed query returns the same unknown bit up to a known correction. At the root, the outcome is ℓj(σ)\ell_j(\sigma)ℓj​(σ). If one heap changes from hhh to h′h'h′ (for example when evaluating a candidate move), the nim-sum changes by h⊕h′h\oplus h'h⊕h′, and by linearity the outcome becomes ℓj(σ)⊕ℓj(h⊕h′)\ell_j(\sigma)\oplus\ell_j(h\oplus h')ℓj​(σ)⊕ℓj​(h⊕h′), where the correction is computable from the known heap values.

So one channel yields one unknown bit of the BBB-bit invariant, however often it is queried in this way.

Caveat: this concerns one member of the structured family, not arbitrary rollout policies.
