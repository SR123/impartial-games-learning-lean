Section 8.3, paragraph 1Some impartial games (Geography) have PSPACE-complete winner problems

External cited result A published result used as background or input; not proved in Lean here.

1 Paper text

By Sprague–Grundy theory, every finite impartial game position has a nimber. However, the computational complexity of determining nimbers varies widely. Some impartial games have PSPACE-complete winner problems, such as directed vertex Geography (Schaefer, 1978). Unless P=PSPACE\mathrm P=\mathrm{PSPACE}P=PSPACE, no polynomial-time algorithm solves all such instances. Having a nimber does not supply an efficient way to compute it.

2 Explain this

Every finite impartial game position has a nimber, but computing it can be very hard. For directed vertex Geography the winner problem is PSPACE-complete (Schaefer, 1978); unless P = PSPACE, no polynomial-time algorithm solves all instances. Existence of a nimber gives no efficient way to compute it.
