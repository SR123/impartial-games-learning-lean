2 Explain this

A NIM position is a list of heap sizes. A move picks one nonempty heap and replaces it by any strictly smaller size. Example: from (3,5,6)(3,5,6)(3,5,6) one legal move is (3,4,6)(3,4,6)(3,4,6); (3,5,7)(3,5,7)(3,5,7) is not a move (heaps never grow), and neither is (2,4,6)(2,4,6)(2,4,6) (two heaps changed).

3 How this is formalised

Game.Move: qqq is reached from ppp when $p = \mathit{pre} \mathbin{+!!+} [x] \mathbin{+!!+} \mathit{post}andandandq = \mathit{pre}\mathbin{+!!+}[y]\mathbin{+!!+}\mathit{post}withwithwithy<x$: exactly one heap strictly decreases and the heap positions stay aligned. Game.move_sum_lt proves that every move lowers the total number of stones, which is how termination is proved throughout.
