Section 7.2.2, paragraph 1Teacher–random–teacher dataset of 10⁶ examples with soft optimal-move labels

We generate a dataset of size D=106D=10^6D=106 examples of the form (p,p′)↦πopt(⋅∣p′),(p, p') \mapsto \pi_{\mathrm{opt}}(\cdot \mid p') ,(p,p′)↦πopt​(⋅∣p′), where πopt(⋅∣p′)\pi_{\mathrm{opt}}(\cdot \mid p')πopt​(⋅∣p′) is a soft target distribution over optimal moves from p′p'p′.

2 Explain this

Each training example is built in three steps: take a random winning position and apply an optimal move (so the result ppp has nim-sum zero); apply one uniformly random legal move to get p′p'p′; label p′p'p′ with the uniform distribution over all optimal moves. This reproduces exactly the restoration situation: the opponent departs from a PPP-position and the agent must restore it. There are 10610^6106 examples, split 80/10/10 with seed 0.

The paper notes two ways in which this helps the learner compared with earlier studies: binary heap encoding, and perfectly labelled restoration targets instead of sparse win/loss outcomes. It also notes that the teacher's first-winning-heap rule makes the distribution of predecessors nonuniform.

3 How this is formalised

How this is covered. Empirical setup, described from the saved run. The fact that ppp has nim-sum zero and that every label move restores zero follows from Section 7.2, paragraph 1. The dataset itself is not part of this edition.
