1 Paper text

Early stopping. The average number of shootouts is 2.87 rather than the worst-case 4, because any N-position with σ0=1\sigma_0 = 1σ0​=1 is caught at head 0 (one rollout); only those with σ0=0\sigma_0 = 0σ0​=0 require further heads. Scope. We report the saved seed-7 configuration above. Perfect classification on this finite test set does not establish all-position correctness, robustness across seeds, or successful self-play discovery. We make no broader sweep claim without corresponding run records.

2 Explain this

The controller used 2.87 rollouts on average instead of the worst case 4, because every NNN-position with σ0=1\sigma_0=1σ0​=1 is detected by head 0 after one rollout; only positions with σ0=0\sigma_0=0σ0​=0 need further heads (and PPP-positions always need all four). The result is for the saved seed-7 configuration and does not establish correctness on all positions, robustness across seeds, or self-play discovery.

3 How this is formalised

How this is covered. The 2.87 average is empirical. That the depicted controller stops after one query when head 0 reports 1, and uses at most BBB queries, is checked (Figure 3).
