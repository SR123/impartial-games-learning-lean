2 Explain this

The grid. Every weight and threshold is a multiple of 1/D1/D1/D between 000 and W/DW/DW/D: for example, with D=4D=4D=4 and W=8W=8W=8 the allowed values are 0,0.25,0.5,…,20, 0.25, 0.5, \dots, 20,0.25,0.5,…,2. The point is that this set is fixed: it does not grow when the input gets longer.

Why negative terms matter. The model only has nonnegative weights on literals (an input xxx or its negation 1−x1-x1−x). A signed term −a x-a\,x−ax can be rewritten as a(1−x)−aa(1-x) - aa(1−x)−a, so it becomes a nonnegative weight on the negated literal, but the threshold rises by aaa. With many negative terms the threshold can grow with the input length and leave the grid. So "signed weights" are not automatically inside the model.

3 How this is formalised

A gate in Lean (AC0.Gate) stores integer coefficients aja_jaj​, negation flags and an integer threshold bbb; with denominator DDD the paper's weights are aj/Da_j/Daj​/D and the threshold is b/Db/Db/D. AC0.gate_rat_iff proves that the paper's rational Heaviside form fires exactly when the integer form b≤∑jaj[zj⊕ηj]b\le\sum_j a_j[z_j\oplus\eta_j]b≤∑j​aj​[zj​⊕ηj​] does (for D>0D>0D>0). Fixed-scale validity, AC0.Gate.Valid, bounds the threshold and coefficients by WWW.

The remark about signed terms is the identity Windows.literal_shift: over the integers, θ≤s−ax  ⟺  θ+a≤s+a(1−x)\theta\le s-a x \iff \theta+a\le s+a(1-x)θ≤s−ax⟺θ+a≤s+a(1−x).
