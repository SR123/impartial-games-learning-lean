Theorem 5.2 (Single-frame parity barrier) Consider the restricted family of NIM positions P(b)=(2,b1,…,bm)P(\mathbf{b})=(2,b_1,\dots,b_m)P(b)=(2,b1​,…,bm​) where bi∈{0,1}b_i\in\{0,1\}bi​∈{0,1}. 2 Explain this

The reduction. Look at boards (2,b1,…,bm)(2,b_1,\dots,b_m)(2,b1​,…,bm​) where each bib_ibi​ is 000 or 111. The nim-sum is 2⊕(b1⊕⋯⊕bm)2\oplus(b_1\oplus\cdots\oplus b_m)2⊕(b1​⊕⋯⊕bm​), which is 222 or 333, so every such board is winning. Only the first heap has the 222s bit, so a winning move must change the first heap, and the only value that makes the nim-sum zero is b1⊕⋯⊕bmb_1\oplus\cdots\oplus b_mb1​⊕⋯⊕bm​.

Example. (2,1,0,1)(2,1,0,1)(2,1,0,1): parity 000, so the winning move is 2→02\to02→0. (2,1,1,1)(2,1,1,1)(2,1,1,1): parity 111, so it is 2→12\to12→1.

Consequence. Any agent that always finds the winning move on these boards computes the parity of bbb: read off the new value of the first heap. With two bits per heap, encoding and decoding are mere wiring, so they keep size and depth unchanged.

3 How this is formalised

  • Game.unique_zero_move: the only legal move from Game.encode bbb to nim-sum zero produces Game.reduced bbb, the board with first heap b1⊕⋯⊕bmb_1\oplus\cdots\oplus b_mb1​⊕⋯⊕bm​ (for every mmm, including m=0m=0m=0).
  • Game.winning_selector_parity: any selector that plays a winning move at every winning position outputs the reduced board on these inputs.
  • ParityCircuit.extraction: circuit form. If a binary move selector (a formula family producing a valid bit, index bits and two value bits) of depth ddd and size sss strongly masters 2-bit boards with m+1m+1m+1 heaps, then a formula of the same depth and size, reading only the mmm parity inputs, computes parity. The encoding is a leaf substitution, so no resources are added.
