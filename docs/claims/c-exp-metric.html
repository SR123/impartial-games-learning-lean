1 Paper text

Restoration accuracy (validation/test). Given a held-out example, the saved evaluation takes the argmax over all action logits and counts it as correct if it lies in the support of πopt(⋅∣p′)\pi_{\mathrm{opt}}(\cdot\mid p')πopt​(⋅∣p′). Illegal predictions therefore count as incorrect, and every legal optimal move is accepted. The saved implementation averages batch accuracies equally, including the shorter final batch, rather than weighting them by batch size. The reported decimals are those saved batch means, not exact correct-example counts divided by 100,000. The same convention applies to the displayed validation curve.

2 Explain this

A held-out example counts as correct if the argmax over all action logits is one of the optimal moves. Illegal predictions are wrong; every legal optimal move is accepted.

A detail that matters for the decimals: the saved code averaged per-batch accuracies with equal weight, including the shorter last batch. The reported numbers are those batch means, not exact counts divided by 100,000.

3 How this is formalised

How this is covered. An empirical definition, including the averaging convention of the saved implementation. Not formalised.
