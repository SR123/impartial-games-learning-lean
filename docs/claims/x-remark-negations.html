Remark B.2Negated inputs replace z_j by ¬z_j in each conjunction; the lemma still applies

Checked theorem Lean checks a formal statement corresponding to this claim.

1 Paper text

Remark B.2 (Negations) If some inputs are negated before weighting, i.e. (zj⊕ηj)(z_j\oplus \eta_j)(zj​⊕ηj​), this simply replaces zjz_jzj​ by either zjz_jzj​ or ¬zj\neg z_j¬zj​ in each conjunction term. Since AC0\AC^0AC0 allows NOT gates, Lemma B.1 still applies.

Generated from paper_jmlr.tex, lines 1437–1440.

2 Explain this

If some inputs are negated before weighting, each term of the DNF simply uses ¬zj\neg z_j¬zj​ instead of zjz_jzj​ for those inputs. AC0 has NOT gates, so the lemma still applies.

3 How this is formalised

Negation flags are part of the Lean gate model from the start, so AC0.gate_ac0 and the DNF correctness theorem AC0.eval_dnf already cover negated inputs.
