2 Explain this

How the flip model of Remark 5.11 fits this setting, and its boundary cases:

  • with fresh independent blocks of LLL flips, the observations follow exactly the channel law above with a=(1−2ε)La=(1-2\varepsilon)^La=(1−2ε)L;
  • for 0<ε<1/20<\varepsilon<1/20<ε<1/2 the small-bias condition a≤1/2a\le1/2a≤1/2 holds for every L≥⌈1/(2ε)⌉L\ge\lceil1/(2\varepsilon)\rceilL≥⌈1/(2ε)⌉;
  • if ε=0\varepsilon=0ε=0 or L=0L=0L=0, one observation is exact;
  • if a=0a=0a=0, no number of observations gets both errors below 1/21/21/2;
  • reusing the same corrupted bit adds no information.
