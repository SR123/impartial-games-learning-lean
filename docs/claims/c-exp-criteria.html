Section 7.1.4, paragraph 1Evaluation by functional correctness on nonzero nim-sum positions and P/N classification

Empirical result Supported by saved experimental runs, not by a proof.

1 Paper text

In this version we report two task-level notions of performance rather than full game-level Elo tournaments. Move-level restoration performance is measured by functional correctness: on a test position with nonzero nim-sum, a move is counted as correct if it produces a successor state with nim-sum zero. Positions with zero nim-sum have no winning move (Theorem 4.4); when reporting functional correctness we therefore condition on nonzero nim-sum positions. Position-level evaluation performance is measured by P/NP/NP/N classification accuracy and NNN-position recall in FSM-controlled shootouts (Section 7.3).

2 Explain this

Two task-level measures are reported instead of full game tournaments: move-level restoration correctness (does the predicted move reach nim-sum zero?), measured only on positions with nonzero nim-sum, since zero-nim-sum positions have no winning move; and position-level P/NP/NP/N classification by the shootout controller.

3 How this is formalised

How this is covered. Empirical definitions. The mathematical fact they rely on, that positions with nim-sum zero have no winning move, is checked (Theorem 4.4).
