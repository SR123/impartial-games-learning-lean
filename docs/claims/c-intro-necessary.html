Section 1, paragraph 4AC0 representability is necessary within the restricted model, not sufficient for training and not universal

1 Paper text

The value of identifying a bottleneck is that it tells us what an architectural change must supply. Instead of asking a shallow network to rediscover a global invariant from every board, we can expose a useful transition, obtain complementary information from rollouts, or accumulate the invariant over time. Our contribution is this barrier-to-bypass approach: a computational obstruction guides three concrete constructions. Representability in AC0\AC^0AC0 is a necessary condition for a fixed-latency computation in our restricted model; it is neither sufficient for successful training nor a universal condition on what neural networks can learn.

2 Explain this

This sentence states the logical role of AC0 in the paper.

  • Necessary within the model. By Theorem 2.4, anything a fixed-latency network of the restricted kind can compute is in AC0. So if a decision rule is provably not in AC0, no such network can implement it.
  • Not sufficient for training. A function can be in AC0 and still be hard to learn by gradient descent or self-play.
  • Not universal. Networks outside the model (scale-adaptive thresholds, growing depth, ordinary floating-point layers) are not constrained by this argument.

The "barrier-to-bypass" idea is to use the obstruction constructively: it tells us what an architecture must add.

3 How this is formalised

This is an interpretation of Theorem 2.4. The formal content is that theorem (checked in Lean, see Theorem 2.4); the statements about training and about networks outside the model are deliberately not formal claims.
