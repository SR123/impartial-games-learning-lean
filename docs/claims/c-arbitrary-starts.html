Section 5.4, paragraph 3With arbitrary start positions, one rollout of π₀ on the boards of k-th bits returns σ_k(P)

Checked theorem Lean checks a formal statement corresponding to this claim.

1 Paper text

Allowing arbitrary start positions would defeat the single-channel restriction: querying π0\pi_0π0​ on heaps consisting of the kkkth bits of PPP returns σk(P)\sigma_k(P)σk​(P). Likewise, an unrestricted sequential controller could compute the nim-sum itself. The lower bound therefore concerns the stated measurement/readout model, not general MCTS or all single-policy algorithms.

Generated from paper_jmlr.tex, lines 643–643.

2 Explain this

If the planner could start rollouts anywhere, the restriction would be meaningless. Example: build the board whose heaps are the kkk-th bits of the heaps of PPP (each heap becomes 000 or 111). A rollout of π0\pi_0π0​ on it removes one stone per move, so the outcome is the parity of the number of ones, which is bit kkk of the nim-sum of PPP. Doing this for each kkk recovers the whole nim-sum with one policy. So the lower bound must restrict queries.

3 How this is formalised

Misc.bitBoard_query: one rollout of π0\pi_0π0​ on the board of kkk-th bits of PPP returns σk(P)\sigma_k(P)σk​(P); Misc.nimSum_bitBoard is the underlying identity (the low bit of that board's nim-sum is bit kkk of nim⁡(P)\operatorname{nim}(P)nim(P)).
