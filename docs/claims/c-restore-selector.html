2 Explain this

The proposition says which differences to match; this sentence says the matching move can be found by a shallow circuit. Compute δ\deltaδ from the two frames, then pick (by a fixed tie-break) a heap iii with xi′⊕δ<xi′x_i'\oplus\delta < x_i'xi′​⊕δ<xi′​ and set it to xi′⊕δx_i'\oplus\deltaxi′​⊕δ. Under the promise, δ\deltaδ equals the current nim-sum, so such a heap exists: any heap with the top bit of δ\deltaδ set works.

The two examples marked "outside the promise" do not start from a zero-nim-sum board after a legal move, so the guarantee does not apply to them.

Inside the promise. The earlier board has nim-sum 0 and the opponent decreased one heap, so the restoration theorem guarantees that the output restores nim-sum 0.

→→

  1. Compare the frames bit by bit

    Each heap is a 3-bit block. For every heap and every bit position, one two-input XOR compares Q with Q′, all in parallel.

    HeapQ 421Q′ 421XORHeap
    03 0113 011000same
    15 1014 100001changed
    26 1106 110000same

  2. Extract the difference δ

    Bit k of δ is the OR of column k of the XOR table: 001 = δ = 1.

    At most one heap changed, so at most one row is nonzero and the OR equals the XOR of the rows, which is nim(Q) ⊕ nim(Q′).

  3. Propose replacements and test them in parallel

    For every heap at once: replace Q′i by Q′i ⊕ δ and test whether that is a decrease. The decisive bit is the highest set bit of δ (weight 1): a heap passes exactly when it has that bit set.

    HeapQ′ 421Q′ ⊕ δTest
    03 0112 010passes: 2 < 3
    14 1005 101fails: 5 > 4
    26 1107 111fails: 7 > 6
    Show the bit comparisons

    The test x ⊕ δ < x is a fixed-depth circuit: an OR over the possible highest differing bit, requiring equality above it, a 1 in x and a 0 in the replacement at that bit.

    • Heap 0: 011 vs 010 — the highest differing bit has weight 1; the heap has 1 there, so the replacement is smaller.
    • Heap 1: 100 vs 101 — the highest differing bit has weight 1; the heap has 0 there, so the replacement is larger.
    • Heap 2: 110 vs 111 — the highest differing bit has weight 1; the heap has 0 there, so the replacement is larger.

    Candidates passing: 1.

  4. Choose between cancelling and the fallback

    cancelling move At least one replacement passes, so the flags are the passing tests and the fallback is masked off.

    Heappassesnonzerofallback valueflag si

    1014 − 1 = 30

  5. Encode the first flagged heap as a binary index

    For N = 3 heaps the construction uses r = ⌊log2 N⌋ + 1 = 2 index bits (the encoder itself needs only N ≤ 2r). The first flag is at heap 0, so the index bits are 00.

    fi = si ∧ ¬sj for all j < i keeps only the first flag; index bit k is the OR of fi over the heaps i whose binary index has a 1 at bit k. This is a fixed-depth circuit, not a search.

How this relates to the Lean proof. The selector is Family.restS (B, N): the local difference circuits LocalRestore.dC, the candidate tests of SelectCircuit.varSel and the priority encoder PriorityEncoder.encode, read on the two-frame input LocalRestore.tf. Family.rest_semantics proves that, on the promised domain, these formulas and the compiled network output a legal move that restores nim-sum 0. Outside the promise the circuit still computes the values shown, and no theorem says that the result restores 0.

What this does not show. The selector does not find a first winning move from an arbitrary board. Given a zero-nim-sum predecessor it maintains the invariant (Theorem 5.12(iii)). The boxes of Figure 7 group operations; the stages here group gates, not network layers.

3 How this is formalised

  • LocalRestore.restore_equiv: for BBB-bit boards of equal length NNN, if nim⁡(Q)=0\operatorname{nim}(Q)=0nim(Q)=0 and Q→Q′Q\to Q'Q→Q′ is legal, the explicit circuit LocalRestore.restC (which reads only per-heap bit differences of the two frames) outputs a move (i,v)(i,v)(i,v); applying it gives exactly the board specified by the global definition Game.restore; the move is legal; the result has nim-sum zero.
  • LocalRestore.restC_bound: depth at most 17 and polynomial size, reading only the two frames.
  • Family.rest_semantics: the same objects in the paper's binary output format (valid bit, binary index, binary value), both as formulas and as the compiled threshold network with weights and thresholds in {0,1}\{0,1\}{0,1}.
  • WholeGame.twoFrame_wins: a player that stores its own last board and answers every legal opponent move with the network's reply wins every play from an established zero-nim-sum board.
