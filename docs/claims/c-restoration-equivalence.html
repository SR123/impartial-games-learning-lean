Section 7.2, paragraph 1After any move from a zero-nim-sum position, every optimal reply restores nim-sum zero

Checked theorem Lean checks a formal statement corresponding to this claim.

1 Paper text

This experiment isolates the restoration response as a supervised learning problem. In normal-play impartial games, a restoration response is the move that returns play to a losing (PPP-)position after the opponent departs from it. In Nim, this is equivalent to selecting an optimal (winning) move from the post-opponent position: if the previous position had nim-sum 000, then after any opponent move the position is winning, and any optimal reply restores nim-sum 000.

Generated from paper_jmlr.tex, lines 1041–1043.

2 Explain this

In NIM, "restore after the opponent leaves a PPP-position" is the same task as "find a winning move from the current position", provided the previous position had nim-sum zero: any opponent move from a zero nim-sum produces a nonzero one (a winning position for the agent), and every optimal reply returns to zero.

3 How this is formalised

Game.move_from_zero (every legal move from nim-sum zero reaches a nonzero nim-sum), Game.exists_move_to_zero (a move back to zero exists) and Game.lose_iff (the positions with nim-sum zero are exactly the losing ones, so "optimal" means "to nim-sum zero").
