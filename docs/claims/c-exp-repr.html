Section 7.1.1, paragraph 1Experimental state and action representation (binary heaps, set-heap actions, unmasked restoration argmax)

Empirical result Supported by saved experimental runs, not by a proof.

1 Paper text

We use a fixed-width binary encoding of heap sizes with kkk bits per heap. The single-frame input is the encoding of the current heap vector. The two-frame input concatenates the encodings of the previous and current heap vectors. When a previous frame is unavailable (e.g. on the first move of a game), we set the previous frame equal to the current position so that the input dimension is constant and the 2F policy remains well-defined.

Generated from paper_jmlr.tex, lines 1003–1005.

2 Explain this

Setup facts for both experiments: heaps are written in binary with kkk bits; the one-frame (1F) input is the current board, the two-frame (2F) input concatenates previous and current boards (on a first move the previous frame is set equal to the current one). Actions are "set heap iii to value vvv", giving N⋅2kN\cdot2^kN⋅2k logits.

Two evaluation conventions are distinguished: restoration accuracy takes an unmasked argmax over all logits (an illegal prediction counts as wrong), while game play and the rollout routines mask illegal moves.

3 How this is formalised

How this is covered. A description of the saved experimental implementation, taken from the paper; the edition reproduces it unchanged and does not re-run anything. It is not formalised. The formal model of Section 2 (fixed-scale literal-threshold gates) is different from these floating-point networks.
