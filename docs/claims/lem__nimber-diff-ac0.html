Lemma 5.4With at most t changed heaps (t fixed), Δ is computed by polynomial-size constant-depth circuits

1 Paper text

Lemma 5.4 (Bounded-change differences) Fix a constant t∈Nt\in\Nt∈N. Let PPP and P′P'P′ be NIM positions whose heap vectors differ in at most ttt heaps. Then Δ(P,P′)\Delta(P,P')Δ(P,P′) can be computed by an AC0\AC^0AC0 circuit of polynomial size (in the input length).

2 Explain this

The statement. If two boards differ in at most a fixed number ttt of heaps, their nimber difference can be computed by an AC0 circuit.

Why. Compare the two boards heap by heap to find which heaps changed (a local test), XOR each changed pair, and XOR together at most ttt such values, which is a constant-size parity. The circuit has to find where the changes are; it does this by trying every possible set of at most ttt changed heaps in parallel (O(Nt)O(N^t)O(Nt) sets).

Why it matters. It is the formal core of the two-frame bypass: the transition is easy even though the state is hard.

Caveat. ttt must be a constant: the depth bound grows with ttt and the size bound is polynomial with an exponent depending on ttt. With an unbounded number of changes the problem becomes global parity again.

Inside the promise. The earlier board has nim-sum 0 and the opponent decreased one heap, so the restoration theorem guarantees that the output restores nim-sum 0.

→→

  1. Compare the frames bit by bit

    Each heap is a 3-bit block. For every heap and every bit position, one two-input XOR compares Q with Q′, all in parallel.

  2. Extract the difference δ

    Bit k of δ is the OR of column k of the XOR table: 001 = δ = 1.

    At most one heap changed, so at most one row is nonzero and the OR equals the XOR of the rows, which is nim(Q) ⊕ nim(Q′).

  3. Propose replacements and test them in parallel

    For every heap at once: replace Q′i by Q′i ⊕ δ and test whether that is a decrease. The decisive bit is the highest set bit of δ (weight 1): a heap passes exactly when it has that bit set.

    The test x ⊕ δ < x is a fixed-depth circuit: an OR over the possible highest differing bit, requiring equality above it, a 1 in x and a 0 in the replacement at that bit.

    • Heap 0: 011 vs 010 — the highest differing bit has weight 1; the heap has 1 there, so the replacement is smaller.
    • Heap 1: 100 vs 101 — the highest differing bit has weight 1; the heap has 0 there, so the replacement is larger.

How this relates to the Lean proof. The selector is Family.restS (B, N): the local difference circuits LocalRestore.dC, the candidate tests of SelectCircuit.varSel and the priority encoder PriorityEncoder.encode, read on the two-frame input LocalRestore.tf. Family.rest_semantics proves that, on the promised domain, these formulas and the compiled network output a legal move that restores nim-sum 0. Outside the promise the circuit still computes the values shown, and no theorem says that the result restores 0.

What this does not show. The selector does not find a first winning move from an arbitrary board. Given a zero-nim-sum predecessor it maintains the invariant (Theorem 5.12(iii)). The boxes of Figure 7 group operations; the stages here group gates, not network layers.

3 How this is formalised

The two frames are laid out as one bit vector (LocalRestore.tf). For each bit qqq, the circuit LocalRestore.bdC B N t qB\ N\ t\ qB N t q is built from per-heap comparisons and exact "at least kkk of these heaps differ in bit qqq" counters (valid because at most ttt heaps differ).

  • LocalRestore.bdC_eval: if at most ttt heaps differ, the circuit outputs bit qqq of nim⁡(Q)⊕nim⁡(Q′)\operatorname{nim}(Q)\oplus\operatorname{nim}(Q')nim(Q)⊕nim(Q′).
  • LocalRestore.bdDelta_eq: the BBB output bits assemble to exactly that number.
  • LocalRestore.bdC_res: depth at most 2t+82t+82t+8, size at most (2t+6)(N+t+11)3t+6(2t+6)(N+t+11)^{3t+6}(2t+6)(N+t+11)3t+6, reading only the two frames.

The construction differs in detail from the subset enumeration of Appendix E (it counts instead of enumerating subsets) but proves the same lemma with explicit bounds.
