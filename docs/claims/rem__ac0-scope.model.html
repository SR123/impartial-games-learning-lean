Remark 2.2 (model scope)The model has bounded thresholds; a fan-in-dependent threshold such as majority lies outside it

Checked definition or construction Lean contains the definition or construction, with checked properties.

1 Paper text

Remark 2.2 (Scope of the AC0\AC^0AC0 abstraction) Theorem 2.4 formalises a fixed-latency fixed-scale quantised regime in which each unit uses parameters drawn from a bounded-range grid QW,D\Qset_{W,D}QW,D​ with W,DW,DW,D independent of the input length. This yields the constant-witness property exploited in Lemma B.1.

The abstraction is deliberately conservative: it does not model architectures that rely on fan-in dependent re-scaling, numerically large signed biases/thresholds that grow with dimension, or deep computations whose depth scales with nnn. Allowing such scale-adaptive behaviour leads naturally to richer threshold-circuit models (e.g. TC0\TC^0TC0), in which parity-like computations can become representable.

2 Explain this

The remark says what the abstraction deliberately leaves out: fan-in-dependent re-scaling, large signed biases that grow with dimension, and computations whose depth grows with nnn.

Concrete example: majority of mmm bits is a threshold gate with all weights 111 and threshold ⌈m/2⌉\lceil m/2\rceil⌈m/2⌉. Its weights are on the grid, but its threshold grows with mmm. So majority is not in the model once m>2Wm>2Wm>2W, even though "all coefficients lie in a finite set". This is why the model bounds thresholds, not only weights.

3 How this is formalised

Windows.majGate_not_valid: for every WWW and every m>2Wm>2Wm>2W, the {0,1}\{0,1\}{0,1}-coefficient majority gate Windows.majGate is not valid for the grid bound WWW (AC0.Gate.Valid). This checks the precise reason why finite coefficient sets alone do not give the constant-witness property.

Prose-to-formal notes

The remark describes what the model leaves out. Lean checks the precise boundary case: a majority gate with coefficients in {0,1}\{0,1\}{0,1} has threshold ⌈m/2⌉\lceil m/2\rceil⌈m/2⌉, which exceeds every fixed WWW once m>2Wm>2Wm>2W.
