2 Explain this

When a move changes only heap iii from xix_ixi​ to xi′x_i'xi′​, all other heaps appear in both nim-sums and cancel, so Δ(P,P′)=xi⊕xi′\Delta(P,P') = x_i\oplus x_i'Δ(P,P′)=xi​⊕xi′​. Example: (3,5,6)→(3,4,6)(3,5,6)\to(3,4,6)(3,5,6)→(3,4,6) gives Δ=5⊕4=1\Delta = 5\oplus4 = 1Δ=5⊕4=1.

So computing Δ\DeltaΔ needs only the changed heap, not a parity over all heaps.
