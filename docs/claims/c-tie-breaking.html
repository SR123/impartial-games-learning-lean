1 Paper text

Training the rollout heads. We train a shared-trunk network with B=4B=4B=4 policy heads by imitation learning against the structured policies π0,…,πB−1\pi_0,\dots,\pi_{B-1}π0​,…,πB−1​ from Proposition 5.9. Each head πj\pi_jπj​ subtracts 2j2^j2j from the leftmost heap of size at least 2j2^j2j (falling back to subtracting 1 from the leftmost nonzero heap). When multiple heaps qualify for the same phase of πj\pi_jπj​ (e.g. several heaps have hi≥2jh_i \geq 2^jhi​≥2j), any choice among them produces a rollout with the same total move count and hence the same parity outcome. We therefore train with soft targets: for each position and head jjj, the label is uniform over all equivalent actions, and the loss is cross-entropy against this soft distribution. This avoids penalising the model for an arbitrary tie-breaking choice among equally valid heaps.

2 Explain this

When several heaps qualify for the same move of πj\pi_jπj​ (for example several heaps of size at least 2j2^j2j), the choice does not matter for the outcome: every complete rollout has the same number of moves, ∑i⌊hi/2j⌋+∑i(hi mod 2j)\sum_i\lfloor h_i/2^j\rfloor+\sum_i(h_i\bmod2^j)∑i​⌊hi​/2j⌋+∑i​(hi​mod2j), whichever eligible heap is used each time. So the training labels can spread probability evenly over all equivalent actions without changing the channel bit.

3 How this is formalised

Rollout.run_length: every complete run of πj\pi_jπj​ (Rollout.Run, built from Rollout.PolicyMove steps with arbitrary tie-breaking) has exactly that length. Rollout.run_parity: its parity is the channel bit of the nim-sum.
