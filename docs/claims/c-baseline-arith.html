2 Explain this

The single-head baseline declares "NNN-position" exactly when r0=σ0=1r_0=\sigma_0=1r0​=σ0​=1. With 4 bits there are 15 nonzero nim-sums, of which 8 are odd: 1,3,5,…,151,3,5,\dots,151,3,5,…,15. So the classifier detects 8/15≈0.5338/15\approx0.5338/15≈0.533 of NNN-positions and never errs on PPP-positions (σ=0\sigma=0σ=0 has σ0=0\sigma_0=0σ0​=0). On a balanced set its accuracy is 12⋅1+12⋅815=2330≈0.767\tfrac12\cdot1+\tfrac12\cdot\tfrac8{15}=\tfrac{23}{30}\approx0.76721​⋅1+21​⋅158​=3023​≈0.767.

Caveat: this describes that particular classifier. It is not the winning-move bound of Theorem 5.12 and not a limit on other classifiers.
