Definition 5.3 (Nimber difference) Given consecutive positions PPP and P′P'P′ in a play sequence, define the nimber difference Δ(P,P′)  =  nim⁡(P) ⊕ nim⁡(P′).\Delta(P,P') \;=\; \operatorname{nim}(P)\ \oplus\ \operatorname{nim}(P').Δ(P,P′)=nim(P) ⊕ nim(P′).

2 Explain this

The nimber difference of two positions is the XOR of their nim-sums. Because XOR is its own inverse, nim⁡(P′)=nim⁡(P)⊕Δ(P,P′)\operatorname{nim}(P') = \operatorname{nim}(P)\oplus\Delta(P,P')nim(P′)=nim(P)⊕Δ(P,P′): the difference is exactly what has to be "cancelled" to get from one invariant to the other.

3 How this is formalised

Lean does not introduce a separate name: the difference is written nimSum P ^^^ nimSum P' wherever it is used. The key property is one_heap_difference (next record).
