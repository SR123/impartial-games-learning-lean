Section 5.4, paragraph 3The controller organises which head is queried and when to stop; it adds no per-step power

1 Paper text

This viewpoint does not increase the per-step computational power of the rollout heads: each πj\pi_jπj​ remains AC0\AC^0AC0-bounded. Instead, the controller organises which AC0\AC^0AC0 head is iterated in a shootout and when to stop querying. Figure 3 depicts a particularly simple controller that turns the BBB structured rollout heads from Proposition 5.9 into a sequential “bit-query” procedure for deciding whether σ(P)=nim⁡(P)\sigma(P)=\operatorname{nim}(P)σ(P)=nim(P) is zero (and hence whether PPP is a PPP-position).

2 Explain this

The controller does not make any single head more powerful: each head is still a shallow policy. What it adds is organisation: which head to run next and when to stop. That is what turns separate channels into a practical procedure.
