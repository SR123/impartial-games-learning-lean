Section 2.1, paragraph 2The abstraction excludes scale-adaptive regimes, which move towards TC0

Informal interpretation Motivation, interpretation or scope; not a formal claim.

1 Paper text

We emphasise that this is not a statement about floating-point arithmetic per se. The abstraction intentionally excludes scale-adaptive regimes where thresholds/biases grow with fan-in or where weights shrink with dimension (e.g. 1/n1/n1/n or 1/n1/\sqrt{n}1/n​ normalisations), which move the analysis toward threshold-circuit classes such as TC0\TC^0TC0.

2 Explain this

The result is about fixed scale, not about floating-point formats as such. What breaks the argument is scale adaptation: thresholds or biases that grow with the fan-in, or weights that shrink like 1/n1/n1/n or 1/n1/\sqrt n1/n​ (as in many normalisation schemes). Those regimes behave like threshold circuits (TC0\mathrm{TC}^0TC0), which can count and hence compute parity.
