2 Explain this

A literal-threshold network of depth LLL: layer 000 is the input; each unit in layer ℓ\ellℓ looks at the previous layer's outputs, possibly negates some of them, takes a weighted sum with grid weights, and outputs 111 if the sum reaches its grid threshold. The output is the last layer (or some of its coordinates). Widths are polynomial in nnn.

Example: with weights 111 and threshold 111, a unit is an OR of its (possibly negated) inputs; with one negated input it is a NOT.

3 How this is formalised

  • AC0.Gate: coefficients aja_jaj​, negation bits ηj\eta_jηj​ and threshold bbb; the gate fires iff b≤∑jaj[zj⊕ηj]b\le\sum_j a_j[z_j\oplus\eta_j]b≤∑j​aj​[zj​⊕ηj​].
  • AC0.Layer and AC0.evalNet: layers of gates reading the previous layer, applied in order.
  • AC0.NetValid: every gate valid for the grid bound WWW.
  • AC0.gate_rat_iff: equivalence with the paper's rational Heaviside form.
  • FiniteNet.netFormula_spec: the explicit finite-input semantics (an nnn-bit input, zero-extended) and its simulation by one formula per output.
