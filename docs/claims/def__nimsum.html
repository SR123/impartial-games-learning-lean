2 Explain this

The nim-sum of heap sizes is their bitwise XOR: write each size in binary and, in each bit position, count the ones; the result has a 1 exactly where that count is odd. Example: 3⊕5⊕63\oplus5\oplus63⊕5⊕6: $011\oplus101\oplus110 = 000,sothenim−sumis, so the nim-sum is,sothenim−sumis0$.

Each bit of the nim-sum is therefore a parity over all heaps, which is what makes it hard for shallow circuits.

3 How this is formalised

nimSum folds Lean's bitwise XOR over the list of heaps (empty board: 000). nimSum_append proves that the nim-sum of two concatenated lists is the XOR of their nim-sums, the basic tool for local reasoning about one changed heap.
