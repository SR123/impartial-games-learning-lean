Section 5.4, paragraph 5Channels versus protocol: heads supply measurement channels, the FSM sequential control

1 Paper text

Integration (channels vs. protocol). It is helpful to reinterpret Part (ii) of Theorem 5.12 in an “information-channel” language: each policy head πj\pi_jπj​ defines a distinct rollout measurement channel which, when iterated to termination, returns a single bit rj=ROπj(P)r_j=\mathrm{RO}_{\pi_j}(P)rj​=ROπj​​(P) that depends on the hidden BBB-bit invariant σ(P)\sigma(P)σ(P) (cf. the identities in Proposition 5.9). With a single head, repeated deterministic root rollouts return the same linear functional ℓ(σ)\ell(\sigma)ℓ(σ); admissible one-heap modifications give its known affine corrections (Proposition 5.10). These measurements supply no further unknown invariant bit. With multiple heads, the agent has access to linearly independent invariant measurements and can reconstruct σ(P)\sigma(P)σ(P) from their outcomes (Proposition 5.9). The finite-state shootout controller introduced above is the natural generalisation of this idea: it does not change what any head can compute, but organises the heads into an adaptive querying protocol—the controller decides which channel to query next (and when to stop, or when to re-query for robustness) based on previously observed rollout outcomes. In this view, multi-head provides the channels, while the FSM provides the sequential control that turns those channels into a practical evaluation procedure.

2 Explain this

A useful way to read Theorem 5.12(ii): each head is a measurement channel returning one bit that depends on the hidden invariant. One head, queried repeatedly at the root, returns the same bit each time; one-heap modifications return known corrections of it. Several heads give independent measurements. The controller is the protocol that decides which channel to query next and when to stop.

3 How this is formalised

An interpretive paragraph. Its formal content is Proposition 5.10 (one channel, affine corrections) and Proposition 5.9 (all channels reconstruct σ\sigmaσ).
