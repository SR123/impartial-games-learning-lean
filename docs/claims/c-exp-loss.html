Section 7.1.3, paragraph 1Soft-target cross-entropy to the uniform distribution over optimal restoration moves

Empirical result Supported by saved experimental runs, not by a proof.

1 Paper text

For each training input (single-frame state or two-frame state-pair), the target is a soft distribution πopt(⋅∣p′)\pi_{\mathrm{opt}}(\cdot\mid p')πopt​(⋅∣p′) over optimal restoration moves. The policy head is trained with cross-entropy to this target. The soft-target cross-entropy also uses unmasked logits. No value loss is used in this supervised restoration experiment.

Generated from paper_jmlr.tex, lines 1026–1029.

2 Explain this

The target for each input is a probability distribution spread evenly over all optimal restoration moves from the current position, and the network is trained with cross-entropy against that soft target (on unmasked logits). No value loss is used.
