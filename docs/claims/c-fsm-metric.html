1 Paper text

The per-head accuracy metric is whether the model’s rollout outcome matches the teacher’s rollout outcome—the correct channel bit—not whether it matches the P/NP/NP/N label directly. Each exact teacher head computes a specified linear functional (r0=σ0r_0=\sigma_0r0​=σ0​; rj=σj⊕σ0r_j=\sigma_j\oplus\sigma_0rj​=σj​⊕σ0​ for j≥1j\ge1j≥1). The learned heads can make channel errors. The FSM uses an OR of the queried outcomes for P/NP/NP/N classification, which is a different task from reconstructing every nim-sum bit.

2 Explain this

Two different things are measured. Per-head accuracy asks whether the learned head's rollout outcome equals the exact teacher's outcome (the correct channel bit). The controller's classification uses the OR of the queried outcomes. A head can be wrong on a channel without changing the final OR decision.

3 How this is formalised

How this is covered. Empirical definitions. The exact teacher heads' channel values are the checked identities of Proposition 5.9; the OR rule is Section 5.4, “Finite-state shootout controller (FSM over policy heads)”.
