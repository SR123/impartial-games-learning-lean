2 Explain this

The compiler turns a Boolean formula into a network with weights and thresholds only 0 or 1. OR uses threshold 1. AND first checks whether any negated input is true, then negates that answer. Values are copied forward until their consumers are ready. This uniform schedule permits two layers per Boolean level plus input and output stages.

From Boolean formulas to threshold layers

Exact trace and teaching example The checked compiler’s exact output is shown beside a hand-made teaching circuit; each part is labelled.

Every gate in these networks has weights and thresholds in {0,1}\{0,1\}{0,1}. An OR gate fires when at least one of its literals is 1. NOT is a negated literal. An AND needs two layers: an OR of the negated inputs (that is, NOT AND), then a negated copy. Choose a formula and set the inputs. The width counts every node of every output formula, duplicates included, so it is far from economical. These numbers describe the uniform construction, not an optimised network and not a trained one.

How this relates to the Lean proof. The grid is the output of ThresholdNet.compileF as Lean evaluates it on these formulas; the browser only evaluates the exported gates. ThresholdNet.compileF_spec proves, for any list of formulas of depth at most ddd, that the network has at most 2d+22d+22d+2 layers and computes every formula exactly. The selector bounds in the table of Appendix C come from this rule: Family.rest_ac0 (Boolean depth at most 20) and Family.rest_net (at most 42 layers with weights and thresholds 0 or 1).

What this does not show. The 42-layer figure is an upper bound for one explicit, deliberately uniform construction. It is not a lower bound, not a layer count measured in an experiment, and not a statement about which networks training finds. A more economical network may use fewer layers: for the small boards in the table, the selector formulas Lean builds have depth 15, so even the uniform compiler produces 32 layers, below the bound of 42. Proving a sharper general bound would need a separate construction and proof.
