Definition A.2Bounded-unrolling recurrence: at most T updates in total from an input-independent initial state

1 Paper text

Definition A.2 (Bounded-unrolling recurrence) Fix a time window T∈NT\in\NT∈N. A fixed-scale quantised RNN\RNNRNN consists of:

  • input bits xt∈{0,1}nx_t\in\bits^nxt​∈{0,1}n at time ttt,

  • a hidden state ht∈{0,1}mh_t\in\bits^{m}ht​∈{0,1}m for some m≤poly(n)m\le \poly(n)m≤poly(n),

  • an output ot∈{0,1}ko_t\in\bits^{k}ot​∈{0,1}k for k≤poly(n)k\le \poly(n)k≤poly(n),

  • fixed-scale quantised parameters (weights/thresholds in QW,D\Qset_{W,D}QW,D​ and optional input negations) shared across time,

such that each update ht+1h_{t+1}ht+1​ and oto_tot​ is computed by a depth-LLL fixed-scale quantised threshold network over the current input and earlier states within the window. Each inference starts from an input-independent initial state, and the entire computation producing its output contains at most TTT recurrent updates. No boundary state may carry additional input-dependent computation from before that window. Unrolling this bounded computation yields a feedforward computation of depth O(L⋅T)O(L\cdot T)O(L⋅T). A bound only on the lag between connected states does not imply this bound on total unrolling; the persistent model in Section 5.5 deliberately allows more than TTT updates.

2 Explain this

A recurrent model with a hidden state, updated by a fixed-depth threshold network that reads the current input and earlier states within a window. The crucial restriction: each inference starts from an input-independent initial state and makes at most TTT updates in total; no state may smuggle in extra computation from before the window. Unrolled, it is a feedforward network of depth O(LT)O(LT)O(LT).

Caveat (stated in the definition): bounding only how far back each update looks does not bound the total unrolling; the persistent model of Section 5.5 deliberately makes more than TTT updates.

3 How this is formalised

  • Windows.window_ac0: for a valid LLL-layer cell reading the input block and the www most recent states (Windows.winIn; state after ttt updates Windows.wState, with an input-independent initial state), the state after TTT updates is computed by formulas of depth at most 3LT3LT3LT reading only the TTT input blocks.
  • Windows.window_size_closed: a closed polynomial size bound for fixed TTT.
  • AC0.rnn_ac0: the one-state version with total unrolling TTT.
