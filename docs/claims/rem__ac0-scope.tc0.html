Remark 2.2 (TC0)Scale-adaptive threshold circuits (TC0) can represent parity-like computations

External cited result A published result used as background or input; not proved in Lean here.

1 Paper text

Remark 2.2 (Scope of the AC0\AC^0AC0 abstraction) Theorem 2.4 formalises a fixed-latency fixed-scale quantised regime in which each unit uses parameters drawn from a bounded-range grid QW,D\Qset_{W,D}QW,D​ with W,DW,DW,D independent of the input length. This yields the constant-witness property exploited in Lemma B.1.

The abstraction is deliberately conservative: it does not model architectures that rely on fan-in dependent re-scaling, numerically large signed biases/thresholds that grow with dimension, or deep computations whose depth scales with nnn. Allowing such scale-adaptive behaviour leads naturally to richer threshold-circuit models (e.g. TC0\TC^0TC0), in which parity-like computations can become representable.

2 Explain this

Once thresholds may scale with fan-in, constant-depth threshold circuits (the class TC0\mathrm{TC}^0TC0) can count and therefore compute parity. The remark mentions this to explain what the model excludes and why: the lower bound holds only for fixed-scale gates.
