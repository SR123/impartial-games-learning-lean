2 Explain this

Board sizes and attention. Within a game the input layout stays aligned: NNN heap rows with BBB bits each, including zero rows for emptied heaps. The theorem concerns a family of these layouts as NBNBNB grows. An attention extension must implement scoring, coefficient selection and aggregation using the permitted gates; alignment alone does not establish this.

What it says. Take any family of networks, one for each input length nnn, in which: the number of units is polynomial in nnn; the number of layers is a fixed constant (and recurrent or attention-style models run for at most TTT steps in total); every operation is a literal-threshold gate with weights and threshold on the fixed grid. Then the function each network computes is computed by an AC0 circuit family, with depth depending only on L,T,W,DL,T,W,DL,T,W,D.

How. Each unit becomes a small DNF (its witness expansion), each layer becomes a constant number of circuit layers, and a recurrent model with at most TTT steps is unrolled into a feedforward one.

Why it matters. Combined with the parity lower bound, it rules out any network of this kind that computes a function whose computation requires global parity, such as winning-move selection in NIM (Theorem 5.2).

Caveats. The model needs nonnegative literal weights, bounded thresholds and Boolean intermediate states. Floating-point networks with signed weights, normalisation that rescales with fan-in, or softmax attention are not covered unless separately reduced to these gates.

3 How this is formalised

Objects. Formulas (Boolean trees with constants, NOT and unbounded fan-in AND/OR) stand for circuits; size counts every node and depth counts NOT nodes as well, which is conservative. Networks are lists of layers of valid gates.

Main steps checked.

  1. One gate: AC0.gate_ac0 (the DNF, from the bounded witness lemma).
  2. One network: AC0.network_ac0: a valid network of LLL layers with fan-ins and widths at most MMM is computed output by output by formulas of depth at most 3L3L3L and size at most 2(2W+3)L(M+1)WL2(2W+3)^L(M+1)^{WL}2(2W+3)L(M+1)WL, reading only its inputs.
  3. Families: FiniteNet.family_finite for networks whose widths are polynomial in the input length, with a single formula per output carrying the semantics, depth, size and input bounds; Family.netFam_ac0 packages this as an AC0 family certificate (Family.AC0Fam) for every network family certificate (Family.NetFam).
  4. Recurrence: Windows.window_ac0: TTT updates of a cell that reads its input block and the www most recent states unroll to formulas of depth at most 3LT3LT3LT, reading only the TTT input blocks.
  5. Attention-style models: Windows.staged_ac0: a model given as KKK stages, each a valid gate network, is one network of depth at most 3KL3KL3KL.

Relationship to the paper. The denominator DDD disappears after clearing denominators: the integer threshold is at most WWW. The theorem's hypothesis (3) "permitted primitives" is the validity of every gate. The Lean statements are nonuniform (they assert existence of formulas for each size); the paper makes no uniformity claim either.

Assumptions and domain

Fixed W,DW,DW,D, a fixed number LLL of layers, polynomially bounded widths and fan-ins, all weights and thresholds on the grid; for recurrent and attention-style models a fixed total number TTT of updates, each stage itself a valid gate network.

Prose-to-formal notes

Lean uses formulas (trees) as circuits; size counts every node and depth counts NOT gates, which is conservative. The attention-style extension is covered only in the gate-realised form of Definition A.3.
