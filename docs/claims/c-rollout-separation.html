Section 8.4, paragraph 1Theorem 5.12(i) bounds one restricted interface, not general single-policy search

Informal interpretation Motivation, interpretation or scope; not a formal claim.

1 Paper text

Theorem 5.12(i) bounds winning-move selection for fixed bit-width, a specified family of root/one-heap measurements and a polynomial-size, constant-depth readout. It does not bound general single-policy search. Within that interface, the BBB structured channels reconstruct the invariant and permit direct move selection. The extra computational resource is the sequential rollout, not the number of neural output coordinates alone. Repeated deterministic measurements of the same affine channel cannot create additional channel bits, but changing the permitted query transformations or controller computation changes the model and can remove that restriction.

2 Explain this

Theorem 5.12(i) is narrow on purpose: fixed bit-width, a specified family of root and one-heap measurements, and a polynomial-size, constant-depth readout. It does not bound general single-policy search. Within that interface, BBB channels reconstruct the invariant. The extra resource is the sequential rollout, not the number of output neurons. Changing the allowed queries or controller computation changes the model and can remove the restriction.

3 How this is formalised

An interpretation of Theorem 5.12 (i) and Section 5.4, paragraph 3 (which shows how arbitrary queries would remove the restriction).
