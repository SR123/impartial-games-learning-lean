Definition 2.1Fixed-scale quantised NN, RNN and LTST models: constant depth, polynomial size, fixed grid, bounded unrolling

Checked definition or construction Lean contains the definition or construction, with checked properties.

1 Paper text

Definition 2.1 (Quantised inference) A network NN\NNNN in this class has constant depth and polynomially many threshold neurons, with weights and thresholds in QW,D\Qset_{W,D}QW,D​. Analogously, fixed-scale quantised RNN\RNNRNN and LTST\LTSTLTST models have constant depth and polynomial size per time step and operate within a fixed time window TTT. For the simulation theorem, TTT bounds the entire unrolled computation from an input-independent initial state, including any computation used to form a retained state.

Generated from paper_jmlr.tex, lines 297–302.

2 Explain this

This definition fixes the class of networks the lower bound is about:

  • constant depth (a fixed number of layers, independent of the input length);
  • polynomially many threshold neurons;
  • weights and thresholds on the fixed grid QW,D\mathcal Q_{W,D}QW,D​;
  • for recurrent and attention-style models, a fixed time window TTT that bounds the entire unrolled computation, including anything used to form a retained state.

Example: a 3-layer network on nnn inputs with n2n^2n2 neurons, all weights in {0,1/2,1}\{0,1/2,1\}{0,1/2,1} and thresholds at most 222, is in the class for every nnn.

Caveat: this is a restricted logical model inspired by bounded numerical resources. It is not equivalent to arbitrary INT8 or fixed-point inference, and ordinary floating-point layers with signed weights are not automatically covered.

3 How this is formalised

The formal model is the literal-threshold gate network of Appendix A (Definition A.1): gates (AC0.Gate) arranged in layers (AC0.Layer), evaluated by AC0.evalNet, with every gate valid for the grid bound WWW (AC0.NetValid). Two checked facts support the definition's use:

  • AC0.gate_ac0: one valid gate is computed exactly by a formula of depth at most 3 (counting NOT) and size at most 1+(m+1)W(2W+1)1+(m+1)^W(2W+1)1+(m+1)W(2W+1) for fan-in mmm;
  • FiniteNet.netFormula_spec: a network of LLL layers on an nnn-bit input is computed output by output by one formula of depth at most 3L3L3L and size at most 2(2W+3)L(M+1)WL2(2W+3)^L(M+1)^{WL}2(2W+3)L(M+1)WL, reading only the nnn inputs.

The recurrent and attention-style parts of the definition are covered by Definition A.2 and Definition A.3.

Assumptions and domain

Nonnegative literal weights; threshold at most WWW in units of 1/D1/D1/D; Boolean intermediate states; for recurrent and attention-style models, at most TTT updates in total from an input-independent initial state.

Prose-to-formal notes

The Lean gate model is the literal-threshold gate of Definition A.1 after clearing denominators. It is not a model of arbitrary INT8 or floating-point inference.
